# Changelog

## 1.0.0 — 2026-10-03

### Changed

- Генерация RIR в `RoomSim.create_rir` считает импульсы отражений пакетом: общая сетка частот через `numpy.interp`, один IFFT на микрофон, дробные задержки `sinc` для всех значимых источников сразу.
- Коэффициент направленности микрофона и источника применяется умножением. Раньше для этого дважды вызывался `lfilter` с фильтром из одного коэффициента.
- Диаграммы направленности из `micro_config` читаются один раз и кэшируются.
- `get_rt60` и `rt60_to_absorption` перенесены в `src/acoustics.py`. `roomSimSingle` по-прежнему их экспортирует. Так убран циклический импорт между `roomSimSingle` и `src/room_sim`.

Результат `create_rir` совпадает с прежней реализацией побитово. Перебор зеркальных источников оставлен в исходном порядке умножения: пакетное умножение коэффициентов отражения расходилось на один бит. Таблица квантованных дробных задержек не используется, потому что она меняет отсчёты.

### Added

- Тесты `tests/test_rir_exact.py` сверяют RIR и перевод RT60 в поглощение с эталонами в `tests/fixtures/`. Запуск: `python -m unittest tests.test_rir_exact -v`.
